# frontend/CLAUDE.md

React 19 + Vite SPA. Design: `docs/SDS.md` section 9. Root rules in `AGENTS.md` still apply.

## Layout

`src/features/<name>/` holds `api.ts`, `queries.ts`, `components/`, `pages/` and colocated `*.test.tsx`. Routing and guards are in `src/routes/`. `src/lib/` holds `api-client.ts` and `query-client.ts`. `src/components/ui/` is generated by shadcn.

## Commands

- `pnpm --filter frontend run dev | build | typecheck | test | test --coverage`
- Add a shadcn component from the repo root with the pinned CLI: `pnpm dlx shadcn@4.23.0 add <name> --cwd frontend --yes`. Preview first with `--dry-run --view`, then write the file with the Write tool (Rule 10); `add` itself writes through the shell. Never use `@latest`.
- One-time init (AB-1001, existing project, so no `--template`): `pnpm dlx shadcn@4.23.0 init --cwd frontend --base radix --preset nova --yes`. It was run in AB-1001 (style `radix-nova`); do not re-run it. The CLI writes many files at once, so run it in a scratch copy first and write the files with the Write tool (Rule 10). `components.json`, `src/lib/utils.ts` (re-exports `cn` from the `cn` package), `src/index.css` and `src/components/ui/` are shadcn-owned.

## Patterns

- Server data lives in TanStack Query only. Zustand is used for exactly two stores: the session (user and in-memory access token) and the editor save state.
- Every fetch goes through `apiFetch`. It attaches the Bearer token, refreshes once on `401 UNAUTHORIZED`, retries once, and never retries auth endpoints.
- Parse every response with the shared Zod schema. Import types from `@note-app/shared`; never redeclare them.
- Route components use `lazy` for code splitting. Guards: `RequireAuth`, `GuestOnly`.
- Forms: react-hook-form with `zodResolver` and the shared request schema. Show server `details` as field errors.
- TipTap autosave: 2 s debounce, one in-flight request, coalesced edits, retries at 2/4/8 s then manual Retry. Warn on leave while unsaved (`useBlocker` and `beforeunload`).
- Search highlights: split the server string on `<mark>` and `</mark>`, decode the five entities, render React text nodes inside `<mark>`.
- Tailwind 4 via the Vite plugin. Use shadcn components before writing custom ones.
- Path alias `@/*` is set with `paths` only; no `baseUrl`.

## Tests

- Vitest + Testing Library + msw (jsdom). Use fake timers for the debounce and retry logic.
- Test the unhappy states: loading, empty, error, and 401 handling.
- Test titles start with `S-AB<ticket>-<nn>`.

## Anti-patterns

- `dangerouslySetInnerHTML`, `innerHTML`, or adding DOMPurify to work around highlighting.
- Storing tokens in `localStorage`, `sessionStorage` or a cookie readable by JS.
- Copying server data into Zustand or component state. Using `useEffect` to fetch.
- Hand-editing files in `components/ui/`.
- Calling `fetch` directly instead of `apiFetch`.
- Allowing editor marks or nodes that `TipTapDocSchema` rejects.
